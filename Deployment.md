# Week 11 — Deployment

## EV Charging Finder

### Expected Deliverable

Deploy the EV Charging Finder application and prepare deployment documentation with a live URL.

---

## Activities

During Week 11, the EV Charging Finder system was prepared for deployment. The frontend, backend, database, and external API services were configured so the application could run in a live environment.

Main activities include:

- Set up hosting for the frontend application
- Deploy React.js frontend
- Deploy Express.js backend API
- Configure environment variables
- Connect backend with MongoDB database
- Configure Mapbox API key
- Configure Open Charge Map API key
- Set up CORS for frontend and backend connection
- Test live API endpoints
- Check login, map, route planner, and station search features
- Prepare deployment documentation

---

## How the App is Deployed

The EV Charging Finder application is deployed using separate hosting services for frontend and backend.

The **frontend** developed using React.js and Tailwind CSS is deployed on hosting platforms such as **Vercel** or **Netlify**.

The **backend** developed using Express.js is deployed on cloud platforms such as **Render**, **Railway**, or **Heroku**.

The **database** is hosted using **MongoDB Atlas**.

External APIs including **Mapbox API** and **Open Charge Map API** are connected through environment variables.
