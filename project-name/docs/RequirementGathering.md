# Define Product Features and System Requirements

## 1. Product Features (Core Features)

The EV Charging Finder system is designed to help electric vehicle users easily locate and access charging stations. The main product features include:

- User registration and login system
- Search for nearby EV charging stations using location services
- Interactive map view displaying charging stations
- Filter charging stations by charger type, availability, price, and distance
- View charging station details (address, charger type, operating hours, pricing)
- Route navigation to charging stations
- Admin dashboard for managing charging station information
- Secure user authentication and data encryption

---

## 2. Primary Users

### EV Drivers
Users who own electric vehicles and need charging stations during travel.

### New EV Users
People who recently purchased EVs and need assistance locating charging facilities.

### Admin
Responsible for managing users, stations, system security, and updates.

| User | Goal |

## 5. User Personas

### Persona 1 – Daily EV Driver

**Goal:** Find available charging stations during daily commute.

**Needs:**

- Fast search results
- Real-time availability
- Distance filter

### Persona 2 – New EV User

**Goal:** Learn and locate suitable charging stations.

**Needs:**

- Easy interface
- Charger compatibility information
- Navigation support

### Persona 3 – Admin

**Goal:** Maintain system accuracy and security.

**Needs:**

- Dashboard access
- User management tools
- Station management system

---

## 6. User Stories

**US1:** As an EV driver, I want to search nearby charging stations so that I can charge my vehicle quickly.

**US2:** As a user, I want to view stations on a map so that I can select the nearest location.

**US3:** As an EV driver, I want to filter stations by charger type so that I can find compatible chargers.

**US5:** As a user, I want to see charger availability before travelling.

**US6:** As a user, I want navigation support to reach charging stations.

**US8:** As an admin, I want to manage user accounts for system security.

---

## 7. System Requirements

### Functional Requirements

- The system allows user registration and login.
- The system shall search for EV charging stations by location.
- The system shall display stations on maps.
- The system shall filter stations by charger type, price, distance, and availability.
- The system shall save favourite charging locations.

### Non-Functional Requirements

- System response time should be fast.
- Interface should be simple and user-friendly.
- System should maintain high availability and reliability.
- Privacy and data protection standards should be followed.-
