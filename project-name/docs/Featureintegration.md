 ## EV Charging Finder

### Expected Deliverable

Connect the frontend and backend to create a working MVP of the EV Charging Finder system.

---

## Activities

During Week 9, the focus is to integrate the frontend with the backend services. The React.js frontend will connect with the Express.js backend API. Mapbox API and Open Charge Map API will also be integrated to support map view, station search, and route planning.

Main activities include:

- Connect React.js frontend with Express.js backend
- Integrate Mapbox API for map display and route planning
- Integrate Open Charge Map API for charging station data
- Implement user login and registration authentication
- Add JWT authentication for protected pages
- Connect search and filter forms with backend APIs
- Display EV charging stations on the map
- Show station details when users select a charging point
- Fix frontend and backend connection issues
- Test API responses and error handling

---

## Questions

### The MVP features that are now fully working include:

- Users can register and log in securely
- Users can search for nearby EV charging stations
- Users can view charging stations on a Mapbox map
- Users can filter stations by location, charger type, distance, and availability
- Users can select a station and view station details
- Users can use route planning to navigate to selected charging stations
- Frontend and backend can communicate through REST API endpoints

---

## Deliverable: Working MVP

By the end of Week 9, the EV Charging Finder system should have a working MVP.

The MVP includes:

- Connected frontend and backend services
- User authentication system
- Mapbox interactive map integration
- Open Charge Map charging station data
- Charging station search functionality
- Filter and station detail features
- Basic route planning functionality

This MVP version is ready for testing, user feedback, and future improvements in the next development phase.
